# Fixtures

## Real (`real/`)

iPhone recordings. They aren't in the repository: they're large and contain location metadata. Tests that need them are skipped when they're missing.

| File | Video | Audio |
|---|---|---|
| `portrait-sdr-h264-30fps-4.8s.mov` | 1920×1080 H.264, SDR Rec. 709, ~30 fps (variable), rotation −90° | AAC stereo 44.1 kHz |
| `portrait-hdr-dolbyvision-60fps-3.3s.mov` | 3840×2160 HEVC Main 10, HLG, Dolby Vision 8.4, 60 fps, rotation −90° | AAC stereo + 4-channel spatial track |
| `portrait-hdr-dolbyvision-59.94fps-5.1s.mov` | 3840×2160 HEVC Main 10, HLG, Dolby Vision 8.4, 59.94 fps, rotation −90° | AAC stereo + 4-channel spatial track |

Not yet covered by a real clip: 240 fps slow motion and landscape.

## Synthetic (`synthetic/`)

Generated by `Scripts/make-fixtures.sh` (`--force` to rebuild). They use ffmpeg’s `testsrc` pattern, whose running timestamp makes timing errors visible in exported frames.

| File | Covers |
|---|---|
| `landscape-sdr-30fps-6s.mov` | Landscape with sound |
| `uhd-landscape-30fps-4s.mov` | 4K, for the 4K output resolution |
| `hdr-hlg-landscape-30fps-4s.mov` | HDR: 10-bit HEVC tagged HLG |
| `silent-landscape-30fps-4s.mov` | No audio track |
| `rotated-portrait-sdr-30fps-5s.mov` | Landscape pixels with a 90° display matrix |
| `vfr-30fps-5s.mov` | Variable frame rate (2 of every 7 frames dropped) |
| `hfr-120fps-4s.mov` | High frame rate |
| `short-2s.mov`, `short-0.8s.mov` | Shorter than the default length and than the 1 s minimum |
| `too-short-0.3s.mov` | Below 0.5 s, rejected at import |
| `long-10min.mov` | Timeline precision on a long source |
| `av-sync-30fps-8s.mov` | A white flash and a 1 kHz beep at the start of every second |
| `framecode-30fps-6s.mov`, `framecode-120fps-4s.mov` | 12 bars spell each frame’s source index in binary |
| `framecode-vfr-6s.mov` | Frame code with 2 of every 7 frames dropped; codes keep their original index |
